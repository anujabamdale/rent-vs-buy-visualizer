# 🏡 Rent vs. Buy Wealth Simulator

An interactive data visualization tool designed to model the long-term financial trade-offs between **buying a home** and **renting while investing the difference**.

🔗 **Live Interactive Demo:** [View Live Visualization](https://anujabamdale.github.io/rent-vs-buy-visualizer/)

---

## 📊 Key Features

* **Real-Time Decision Sliders:** Adjust Target Home Price, Comparable Monthly Rent, Stay Duration (1–30 years), Mortgage Interest Rate, and Expected Stock Market Return.
* **Dynamic D3.js Trajectory Chart:** Compare **Net Wealth (Equity vs. Portfolio)** or switch to **Cumulative Out-of-Pocket Cash Paid** with interactive hover snapshots and an automatic **Breakeven Year** marker.
* **Scenario Pinning & Year Scrubber:** Pin a baseline scenario as a dashed reference line to test "what-if" assumptions side-by-side, or scrub through individual years.
* **Multi-Currency & Loan Toggles:** Switch between **$ USD** and **₹ INR**, toggle **10% / 20% / 30%** down payments, and compare **15-Year vs. 30-Year** mortgages.

## 🛠️ Built With

* **HTML5 & Tailwind CSS** — Responsive, clean UI layout
* **D3.js (v7)** — Interactive SVG line/area charts, scales, and dynamic tooltips
* **Vanilla JavaScript** — Real-time mortgage amortization and compound investment engine
